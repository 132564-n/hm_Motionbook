# 图标资源清单

本项目需要以下图标资源，放置在 `entry/src/main/resources/base/media/` 目录下。

所有图标建议使用 PNG 格式，提供以下尺寸（mdpi / hdpi / xhdpi / xxhdpi / xxxhdpi）。

## 应用图标

| 文件名 | 用途 | 推荐尺寸 |
|--------|------|----------|
| `app_icon.png` | 应用启动图标 | 108x108 |

## 底部导航栏图标

| 文件名 | 用途 | 推荐尺寸 |
|--------|------|----------|
| `ic_home.png` | 首页（默认） | 24x24 |
| `ic_home_filled.png` | 首页（选中） | 24x24 |
| `ic_create.png` | 创作（默认） | 24x24 |
| `ic_create_filled.png` | 创作（选中） | 24x24 |
| `ic_mine.png` | 我的（默认） | 24x24 |
| `ic_mine_filled.png` | 我的（选中） | 24x24 |

## 首页入口图标

## 颜色规范

- 图标默认颜色：`#666666`
- 图标选中颜色：`#007DFF`
- 建议使用单色 SVG 图标，通过 `.fillColor()` 动态着色
