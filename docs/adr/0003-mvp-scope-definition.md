# 0003: MVP阶段功能范围定义

## 状态

Accepted

## 背景

作为个人开发者，需要在有限的时间和资源下确定第一阶段（MVP）的功能范围，确保产品能够快速验证市场并控制成本。

## 决策

MVP阶段聚焦于**基础版本**：图文编辑 + 基础音频 + 作品管理，不包含云端AI服务。

### 功能清单

**图文编辑**：
- 基础图片编辑（裁剪、旋转、滤镜）
- 文字叠加、贴纸
- 多页排版、样式、特效
- 模板套用

**音频创作**：
- 本地录音
- 基础剪辑（裁剪、拼接、音量调整）
- 内置本地音效库
- 简单混音

**作品管理**：
- 草稿保存与恢复
- 作品历史记录
- 导出功能（相册/文件系统）

### 暂不包含的功能

- AI辅助（语音合成、图像生成等云端服务）
- 多平台发布
- 云端存储同步
- 专业音频处理（多轨道、降噪、EQ等）

## 后果

- 优点：
  - 控制开发成本和时间
  - 规避云端AI服务的费用
  - 快速验证核心功能和产品方向
  - 降低技术复杂度
- 缺点：
  - 功能完整性有限
  - 差异化竞争优势较弱
  - 可能影响用户体验

## 后续计划

MVP验证成功后，逐步添加：
1. AI辅助功能（使用免费额度或低成本方案）
2. 云端存储和同步
3. 多平台发布能力
4. 专业音频处理能力
